## 📱 Features

- **Evidentiary-Grade GPS HUD:** Burn-in telemetry with latitude, longitude, altitude, compass azimuth, UTM/MGRS coordinates, speed, and real-time satellites fix.
- **Forensic Verification:** On-device SHA-256 cryptographic pixel binding ensuring photos cannot be manipulated without detection.
- **Automated PDF Inspection Reports:** Export one-click PDF audit sheets with map thumbnails, project codes, notes, and inspector signatures.
- **AI Before & After Comparisons:** Side-by-side and overlay comparison photo composition.
- **Zero-Cloud Local Privacy & Google Drive Sync:** Local sandbox device storage with optional user-authorized Google Drive sync.
- **Mobile Optimized:** 100% responsive for all mobile screen sizes, safe-area notches, and fluid touch scrolling.
